Atalhos de teclado do Windows2×Atalhos para alternar janelas, fechar a janela ativa e abrir o Gerenciador de Tarefas

O que precisa saber

  • Alt + Tab: alterna entre as janelas abertas. Alt + F4: fecha a janela ou o aplicativo ativo.
  • Gerenciador de Tarefas: abre direto com Ctrl + Shift + Esc ou, de modo indireto, por Ctrl + Alt + Del (tela de segurança com a opção do Gerenciador).
  • O atalho Ctrl + Alt + A para o Gerenciador de Tarefas não existe; o material já registra que a FCC o usou como pegadinha.
  • Outros atalhos do quadro do material: Windows + D (área de trabalho), Windows + E (Explorador), Windows + I (Configurações), Windows + L (bloquear), Windows + R (Executar), Windows + Shift + S (recorte).

Armadilhas de banca

  • Ctrl + Tab e Ctrl + F4 valem para guias dentro de um programa (como as abas do navegador); o enunciado falava em janelas abertas, e para elas valem Alt + Tab e Alt + F4, segundo os comentários.
  • Alt + F4 encerra o programa de forma abrupta.

Configurações > Aplicativos > Aplicativos padrão2×Onde se altera o aplicativo padrão (por tipo de arquivo ou navegador)omissão?

O que precisa saber

  • Caminho do material: Configurações > Aplicativos > Aplicativos padrão; ali se escolhe o aplicativo associado a um tipo de arquivo (Escolha os aplicativos padrão por tipo de arquivo).
  • Segundo os comentários, para trocar o navegador padrão do Windows 11: abrir Configurações (Windows + I), clicar em Aplicativos, depois em Aplicativos padrão, localizar o navegador na lista e usar Definir padrão (ou "Definir como padrão").
  • Configurações abre por Menu Iniciar > Configurações ou por Windows + I.

Armadilhas de banca

  • As opções erradas misturam rótulos parecidos (Aplicativos e recursos, Aplicativos do Windows, Aplicativos para sites, Navegadores compatíveis). "Aplicativos e recursos" não é o caminho para definir padrão.
  • O caminho exato de cada tela muda com as versões do sistema; o material avisa para conferir no computador.

Possíveis omissões

Filtro INF-Sistemas-Operacionais, questão 2 (Q3288341), assertiva enunciado: o caminho Configurações > Aplicativos > Aplicativos padrão para definir o Google Chrome como navegador padrão do Windows 11 o material traz esse caminho só para associar aplicativos por tipo de arquivo (Windows 10); a definição do navegador padrão apareceu apenas nos comentários. A banca pode ter cobrado a variação do mesmo caminho.

Explorador de Arquivos: Acesso Rápido1×Como o Explorador de Arquivos oferece atalho às pastas mais usadas

O que precisa saber

  • O Explorador de Arquivos (abre com Windows + E) navega por pastas e arquivos do computador.
  • O Acesso Rápido é um atalho na barra lateral que mostra pastas fixadas e usadas recentemente, como Documentos, Downloads e Área de Trabalho.
  • No Windows 11, uma pasta é fixada nele com o botão direito sobre o nome e a opção Fixar no Acesso rápido.

Armadilhas de banca

  • Segundo os comentários, o Cortana pode ser desativado ou ter o funcionamento limitado nas configurações, e os arquivos enviados à Lixeira podem ser restaurados enquanto estiverem nela (o material confirma a Lixeira na seção 2.2.2).

Explorador de Arquivos: menu Exibir1×Ícone do menu Exibir usado para adicionar colunas de informaçãoomissão?

O que precisa saber

  • No menu Exibir do Explorador de Arquivos, o botão Adicionar colunas permite incluir colunas como Data de modificação, Tipo, Tamanho, Data de criação, Autores, Categorias, Marcas e Títulos; há também a opção de escolher outras colunas.
  • Segundo um comentário, esse botão só fica disponível quando o Explorador está no layout Detalhes; nos demais layouts (ícones, lista, blocos) fica esmaecido.
  • Dica dos comentários: nas questões de ícone, tente deduzir a função pela imagem do ícone.

Armadilhas de banca

  • Classificar por nome ou tipo e mostrar o painel de detalhes são outras ações do mesmo menu, mas o ícone pedido era o de adicionar colunas.

Possíveis omissões

Filtro INF-Sistemas-Operacionais, questão 8 (Q889634), assertiva enunciado: o ícone do menu Exibir do Explorador de Arquivos que adiciona colunas de informação o material trata o Explorador em conceito (arquivos, pastas, Acesso Rápido), sem detalhar o menu Exibir; a informação veio só dos comentários.

Menu Iniciar do Windows 101×Botão de duas barras no canto superior direito da janela do Menu Iniciaromissão?

O que precisa saber

  • Segundo os comentários, as duas barras (que aparecem ao aproximar o mouse, no canto superior direito) servem para dar nome ao grupo de aplicativos.
  • Não confundir com os três tracinhos (botão do lado esquerdo), que expandem o Menu Iniciar.

Armadilhas de banca

  • Confundir o ícone de duas barras (nomear grupo) com o de três tracinhos (expandir o menu).

Possíveis omissões

Filtro INF-Sistemas-Operacionais, questão 7 (Q889635), assertiva enunciado: a função do botão de duas barras no canto superior direito dos grupos do Menu Iniciar do Windows 10 o material não descreve os botões do Menu Iniciar; a informação veio só dos comentários. A questão depende de uma imagem que o material não reproduz.

Painel de Controle e Configurações2×Onde ficam as configurações de região e formato de data e horaomissão?

O que precisa saber

  • O Painel de Controle continua disponível no Windows 10 e 11 (menu Iniciar > Painel de Controle), com as configurações clássicas do sistema; o aplicativo Configurações (Windows + I) é a central moderna.
  • Segundo os comentários, para mudar o formato da data no Painel de Controle exibido por categoria: Relógio e Região > Região, aba Formatos, onde se escolhe o formato de um país ou se personaliza. A opção Data e Hora serve para ajustar o relógio, não o formato.

Armadilhas de banca

  • O enunciado pedia mudar o formato da data, não acertar a data e a hora: caminhos que passam por "Data e Hora" levam ao ajuste do relógio.
  • Os alunos reclamam do caráter decoreba do caminho; o material local não detalha o Painel de Controle por dentro. O Painel de Controle não foi removido do Windows 10.

Prompt de Comando: ipconfig1×Comando do Prompt do Windows que mostra o endereço IPv4omissão?

O que precisa saber

  • O Prompt de Comando (cmd) é a interface de linha de comando do Windows; abre pelo Menu Iniciar digitando "cmd".
  • Segundo os comentários, o comando que mostra o endereço IPv4 é o ipconfig; entre as linhas exibidas aparece "Endereço IPv4". O ipconfig /all traz informações mais detalhadas da conexão de rede.

Armadilhas de banca

  • Os distratores usam nomes que parecem comandos (ipv4, ipaddress) ou atalhos e menus inventados; os comentários não os apresentam como comandos reais.

Possíveis omissões

Filtro INF-Sistemas-Operacionais, questão 4 (Q3089777), assertiva enunciado: o comando digitado no prompt do Windows 10 para obter o endereço IPv4 do computador o material cita o Prompt de Comando apenas como ferramenta, sem listar comandos; o ipconfig veio só dos comentários dos alunos. O capítulo pode simplesmente não ter coberto os comandos.

Windows Defender Firewall x Antivírus1×O que o firewall do Windows 10 faz e o que não faz

O que precisa saber

  • O Windows Defender Firewall é um firewall de rede: bloqueia conexões de rede não autorizadas com base em endereço IP, protocolo ou porta, controlando o tráfego de entrada e saída por regras.
  • Ele não remove vírus, não faz varreduras e não bloqueia a execução de arquivos infectados: isso é papel do Antivírus (Microsoft Defender Antivírus).
  • O Windows Defender Antivírus, no modo ativo, verifica arquivos, corrige ameaças e lista as detectadas nos relatórios de segurança.

Armadilhas de banca

  • Atribuir ao firewall as funções de desativar aplicações, fazer varredura completa, bloquear arquivos infectados ou remover malware: o material atribui tudo isso ao antivírus. O firewall apenas permite ou bloqueia comunicação de rede.
